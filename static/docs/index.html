Pengenalan

Caca Auth adalah Auth-as-a-Service multi-tenant. Setiap aplikasi (tenant) mendapat sepasang API key: caca-sk_ untuk server-side dan caca-pk_ untuk client-side. Kirim X-API-Key di setiap request auth.

Alur Autentikasi

1. Register & Login Email/Password

sequenceDiagram participant C as Client participant A as Caca Auth API participant D as Database participant E as Email Provider C->>A: POST /auth/register (X-API-Key) A->>D: Simpan user (is_email_verified=false) A->>A: Generate access_token + refresh_token A->>E: Kirim email verifikasi (hybrid fallback) A-->>C: 200 tokens + user data Note over C,A: User bisa langsung login & akses endpoint umum C->>A: POST /auth/login A->>D: Cek kredensial + lockout status alt kredensial valid A->>D: Simpan session (device, IP, lokasi) A-->>C: 200 tokens baru else kredensial salah A->>D: Naikkan failed_login_attempts A-->>C: 401 invalid credentials end

2. Refresh Token & Logout

sequenceDiagram participant C as Client participant A as Caca Auth API participant R as Redis participant D as Database C->>A: POST /auth/refresh (refresh_token) A->>D: Validasi hash token, cek revoked/expired A->>D: Revoke token lama, buat sesi baru A-->>C: 200 access_token + refresh_token baru C->>A: POST /auth/logout (access_token, refresh_token) A->>R: Blacklist jti access_token (TTL = sisa masa berlaku) A->>D: Revoke refresh_token di DB A-->>C: 200 logged_out

3. OAuth (Google/GitHub/dkk)

sequenceDiagram participant C as Client participant A as Caca Auth API participant P as OAuth Provider participant D as Database C->>A: GET /auth/oauth/{provider}/start A->>A: Generate state (+ PKCE jika Twitter) A-->>C: authorize_url C->>P: Redirect user ke provider P-->>C: Redirect balik dengan code+state C->>A: GET /auth/oauth/{provider}/callback A->>P: Tukar code dengan access_token A->>P: Ambil user info A->>D: Cari/buat user + simpan OAuthAccount A->>D: Buat session, email otomatis terverifikasi A-->>C: Redirect ke frontend dengan tokens

4. Suspicious Activity Detection

flowchart TD A[Login berhasil] --> B{Lokasi dikenal?} B -->|Tidak| C[Tambah alasan: lokasi baru] B -->|Ya| D{Device dikenal?} C --> D D -->|Tidak| E[Tambah alasan: device baru] D -->|Ya| F{Jam wajar 06-23?} E --> F F -->|Tidak| G[Tambah alasan: waktu tidak biasa] F -->|Ya| H{Ada alasan terkumpul?} G --> H H -->|Ya| I[Kirim email suspicious_activity] H -->|Tidak| J[Selesai, tidak ada alert]

Tenant

POST/tenant/register

Daftar sebagai tenant baru dan dapatkan API key.

{
  "name": "My App",
  "email": "dev@myapp.com",
  "password": "Str0ngP@ss!"
}
POST/tenant/login

Login sebagai tenant untuk melihat dashboard.

Email & Password

POST/auth/register

Header: X-API-Key: caca-sk_xxx. Password minimal 8 karakter, kombinasi huruf besar, kecil, angka, simbol.

{
  "email": "user@example.com",
  "password": "Str0ngP@ss!"
}
POST/auth/login

Login dengan email & password. Akun terkunci otomatis setelah 5x gagal.

POST/auth/refresh

Tukar refresh_token dengan pasangan token baru.

POST/auth/forgot-password

Kirim email reset password (token berlaku 1 jam).

POST/auth/change-password

Butuh email terverifikasi. Validasi password lama.

Magic Link & OTP

POST/auth/magic-link/request

Kirim link login tanpa password ke email (berlaku 15 menit).

POST/auth/otp/request

Kirim kode OTP 6 digit via SMS/WhatsApp (berlaku 5 menit).

POST/auth/anonymous

Login sebagai user anonim tanpa kredensial apapun.

Social Login

GET/auth/oauth/{provider}/start

provider: google, github, apple, facebook, microsoft, twitter, linkedin, discord, instagram.

GET/auth/oauth/{provider}/callback

Redirect otomatis ke frontend dengan token setelah OAuth sukses.

Session & Logout

GET/auth/sessions

List semua device aktif milik user (IP, lokasi, waktu aktif terakhir).

DELETE/auth/sessions/{id}

Revoke satu device spesifik.

POST/auth/logout-all

Logout dari semua device sekaligus.

Profil & Avatar

PATCH/profile

Update nama, bio, tanggal lahir.

POST/profile/avatar

Upload avatar (multipart/form-data), 500KB-5MB, auto-resize ke 512x512.

MFA (TOTP)

POST/mfa/totp/setup

Dapatkan secret & QR code untuk Google Authenticator/Authy/1Password.

POST/mfa/totp/enable

Konfirmasi setup dengan kode 6 digit dari app authenticator.

Health & Metrics

GET/health/db

Status koneksi database & response time.

GET/metrics/overview

DAU, MAU, total user, login success/failure rate (30 hari terakhir).
